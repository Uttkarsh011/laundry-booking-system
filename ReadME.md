# 🧺 Laundry Services Web Application

A modern, responsive, and interactive front-end web application built for a premier laundry and dry cleaning service. This project features a full end-to-end booking workflow, live cart calculation using vanilla JavaScript DOM manipulation, and automated email notifications via EmailJS.

---

## 🚀 Live Demo

- **Deployed on Vercel**: https://laundry-booking-system-nu.vercel.app/ *

---

## ✨ Features

- **Responsive Navigation Bar**: Clean layout with logo, navigation links, and a user profile indicator.
- **Hero Section**: Engaging headline, service summary, 3D illustrative graphics, and a smooth-scroll CTA button to the booking section.
- **Service Achievements Bar**: Highlight banner showcasing business milestones and trust metrics.
- **Interactive Service Catalog & Dynamic Cart**:
  - Live listing of dry cleaning, wash & fold, ironing, stain removal, and specialty garments.
  - Interactive "Add Item" / "Remove Item" buttons that update the cart table in real-time.
  - Automatic total price calculation.
- **Appointment Booking System**: Integrated user detail collection (Full Name, Email ID, Phone Number).
- **Automated Email Notifications**: Uses [EmailJS](https://www.emailjs.com/) to trigger instant confirmation emails upon booking.
- **Quality Highlights & Value Propositions**: Grid showcasing core services, delivery reliability, quick support, and affordability.
- **Newsletter Subscription Section**: Engaging community subscription banner.
- **Comprehensive Footer**: Quick navigation links, contact info, and social media handles.
